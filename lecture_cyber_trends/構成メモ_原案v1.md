## 構成と時間配分(合計80分)

- **導入(5分)** スライド3〜4
  - 3つの地殻変動(常態化・AI・量子)と、主張「基本に帰着する」を先出し
- **第1章 サイバー攻撃の近況(15分)** スライド5〜10
  - Colonial/アサヒ → Norsk Hydro(対応の巧拙) → Trisis/イラン製鉄所(安全系) → 戦争との融合 → 「守り切れない」
- **第2章 AIの新局面 ― Mythos問題(25分)** スライド11〜20 ★本講義の新規部分
  - 事実パート: AI進歩年表 → GTG-1002(初のAI実行型攻撃, 2025.11) → Mythosの能力(2026.4) → サンドボックス脱出 → Project Glasswing(防御側) → 公開停止と寡占(2026.6)
  - 姿勢パート(原稿ベース): サイバーだけのAIは従来の枠組みを超えない → 物理的安全対策が拠り所 → 検知重視・停止・早期復旧・基本に立ち返る
- **第3章 量子という時限爆弾(15分)** スライド21〜27
  - 技術1枚 → HNDL → モスカの不等式 → 標準・期限(2030/2035, CRYPTREC) → 民間実装 → 移行5ステップ
- **第4章 規制という外圧(10分)** スライド28〜30
  - CRA/JC-STAR等 → 日本の規制 → AI統制・量子期限も同じ構図(規制=梃子)
- **第5章 守り切れない前提の対策(10分)** スライド31〜33
  - レジリエンス(隔離・代替・停止) → SBOM・ゼロトラスト・共通モデル
- **まとめ(5分)** スライド34〜35
  - 「AIも量子も分解すれば我々の土俵」+ 明日からの3アクション
