# IMANE-DEMO — Figure / In-Image Text Translation Guide

author callouts) in the deck and therefore could not be edited as normal text.
All normal (editable) slide text has already been translated to English in
`IMANE-DEMO_EN.pptx`. The same per-slide translations below are also embedded into
each slide's **speaker notes** in that file.

Client, the phishing email) reflect the **actual demo system**, which is itself in
Japanese. They are translated here for reference so trainees can follow the on-screen
steps; the live VMs will still show Japanese.
